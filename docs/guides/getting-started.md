# CloudSpend AI User Guide

## Getting Started

### Prerequisites
- Python 3.11+
- Node.js 20+
- Docker (optional)

### Installation

1. Clone the repository
2. Install backend dependencies:
   ```bash
   cd backend
   pip install -r requirements.txt
   ```

3. Install frontend dependencies:
   ```bash
   cd frontend
   npm install
   ```

### Running the Application

#### Backend
```bash
cd backend
python main.py
```

#### Frontend
```bash
cd frontend
npm run dev
```

## Features
- Real-time cost monitoring
- AI-powered optimization recommendations
- Cost forecasting
- Multi-cloud support
